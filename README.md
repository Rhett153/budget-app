# Budget App

A responsive personal budgeting dashboard demo built with fictional Canadian-dollar sample data. Open `index.html` in a browser to explore it.

## Demo features

- Monthly income, spending, remaining budget, and net-worth summary
- Cash-flow visualization and spending-category progress
- Recent transactions, sample statement cards, and a savings goal
- Interactive one-click sample budget plan
- Statement selection and account action demos with clear local-only messaging

## Privacy and scope

This is a front-end demo. It does not connect to banks, parse or upload statements, store financial data, or provide financial advice. All names, accounts, and transactions shown are fictional.

## Run locally

No build step or dependencies are required. Open `index.html` directly, or serve this directory with any static web server.
